01

为什么需要它

线上问题排查要翻的服务器日志,经常几百 MB 起步,而且通常按大小或日期自动分块。 VSCode 直接打开这类文件就废 — 打开慢、滚动卡顿、搜索要等几分钟,跳不到想去的行。

Open Log Viewer 接管这件事:按「单块日志」设计,一块一块看正好是排查的自然节奏。 打开时整块载入并显示真实进度,载入完成后搜索 / 过滤 / 翻页都在内存里即时完成; 跳转到行 / 时间走流式定位,只读目标行附近的上下文,不用重新载入。 排查要用的工具它也配齐了 — 多关键词搜索、级别 / 线程 / 时间过滤、时间线、书签 / 注释,还有把固定流程存成一键重跑的排查模板。

标注数据存在用户级存储,排查模板分享走剪贴板或 JSON,全程不依赖工作区。

02

核心能力

01 · I/O

整块载入与分页浏览

打开时整块载入,磁盘读取全程流式,进度按真实字节推进(百分比、已读行数),不是转圈假动画。 载入后分页浏览,每页只渲染当前页的行(50 到 1000 行可调),百万行日志翻页也不卡; 跳转到行 / 时间走流式定位,只读取目标行附近 ±500 行上下文。

  • 多文件同时打开,各占独立面板,状态互不干扰
  • GBK / UTF-16 编码自动识别,「编码」下拉可按面板手动切换
  • 几百 MB 到 1GB 的超大文件也能正常打开,导出同样分批进行并显示进度;超过大小上限(默认 1GB,可调)会明确提示而不是卡死
  • 加载失败 / 编码异常时给出明确错误
02 · SEARCH

多关键词搜索 + 高级搜索

搜索框支持多关键词,空格分隔即 AND 匹配,比如 error timeout 只命中两个词同时出现的行。 勾选「正则」切正则模式,勾「当前页」只在当前显示的页内定位。

高级搜索是查询构建器:每行一个条件(关键词 / 线程名 / 类名 / 方法名 / 级别 / 时间范围), 行间「且/或」芯片切换整体逻辑,底部实时预览这次查询会做什么。 所有条件叠加,「取消筛选」一键清空。

  • 全局搜索历史 50 条,聚焦搜索框一键重搜
  • 行号范围限定:右键任意行设起点 / 终点,浏览、搜索、筛选只在范围内进行
  • 筛选条件芯片式展示,点芯片上的 × 单独取消那一条
  • 折叠重复日志时,徽标显示当前搜索的命中数
03 · NAVIGATE

时间线导航

把整个文件按时间采样画成分布图,点哪跳到哪,当前浏览位置高亮跟着走, 随时知道自己在哪个时间段。采样密度可在设置里调(默认 200,范围 20 – 1000)。

  • 按时间过滤、跳转到指定时间
  • 统计面板给出总行数、各级别数量、时间范围
04 · TEMPLATE

排查模板

固定排查流程存成模板,自动重跑,换个订单号或 traceId 就能复用。 五种动作自由编排:查询日志、筛选、限定范围、打书签、加注释, 动作间自动传上下文(比如从命中行提取线程名接着筛)。

  • 命中多条时可配置「让我选择 / 保留全部 / 自动选第一条」
  • 零命中时可配置终止或跳过继续
  • 「限定范围」把命中行设为范围起点 / 终点,自动圈出单次执行
  • 可视化与 JSON 双形式编辑,导入导出走剪贴板或文件
05 · ANNOTATE

书签、注释、高亮规则

双击日志行加书签,右键命名(留空默认「行 N」);注释从右键菜单发起,列表集中管理。 内置 ERROR / WARN / INFO / DEBUG、时间戳、线程名高亮规则,也支持自定义正则规则。

  • 书签行整行主题色高亮,列表可一键导出书签日志
  • 注释可编辑、删除,方便团队协作分析
06 · FOLD

折叠长行

一行几千字符的超长 JSON,换行后能把一页撑成几百屏,滚轮滚不到头。 折叠长行默认开启:真正放不下的行只显示前 3 行,切口处有醒目的「⋯ 展开」按钮, 点击展开全文、再点「收起」折回 —— 滚轮几格就掠过一页,扫线索只看每条开头就够了。

  • 只折叠真正被裁掉的行,没有「点了没反应」的假折叠
  • 双击加书签不受影响;跳转(定位 / 书签 / 时间线)到长行自动展开
  • 行尾 JSON 解析树首行有「复制 JSON」按钮,一键拿格式化好的 JSON 数据;展开后旁边就能「收起」
  • 折叠重复日志模式下超长行同样折叠;保留行数 1 – 50 可调
03

支持的日志格式

查看器本身是通用文本查看器,任何 .log / .txt 都能打开、搜索、加书签。 在此基础上自动识别时间戳和日志级别 (归一化到 ERROR / WARN / INFO / DEBUG 四档,FATAL、SEVERE 计入 ERROR,TRACE、VERBOSE 计入 DEBUG)。 下表是常见日志组件默认 / 典型输出的实测情况。

日志组件 时间戳 级别
Logback / Log4j / Log4j2 / SLF4J、Spring Boot 默认格式识别识别
log4net / NLog(.NET)识别识别
Python logging(%(asctime)s 格式)、Gunicorn识别识别
logrus、zap 控制台格式(Go)识别识别
Rails、Laravel / Monolog、winston 文本格式识别识别
Go 标准库 log、IIS W3C、syslog RFC5424识别—
Docker json-file、bunyan(JSON 内含 ISO 时间字段)识别—
Tomcat catalina(JUL)、JBoss / WildFly 默认 pattern—识别
Serilog Console 默认、Apache error log—识别
Python logging 默认格式、uvicorn(INFO: 前缀)—识别
nginx / Apache access log(01/Jan/2024 英文月份日期)——

识别不到时间戳只影响时间范围过滤、时间线、按时间裁剪这三类功能,打开、搜索、级别过滤、书签、注释全部照常可用。 级别简写 E / W / I / D、ERR / WRN / INF / DBG / TRC 默认就能识别; 如果你们的日志用了别的缩写,在设置里配级别别名即可。 编码同样自动识别:GBK(含 GB2312,按 GB18030 解码)与 UTF-16 LE / BE (常见于 PowerShell 重定向产物)直接打开不乱码,也可在「编码」下拉手动切换。

06

安装

要求:VSCode 1.75 或更高版本。

方式 A · 扩展市场(推荐)

在扩展面板搜索「Open Log Viewer」或「Open Log Viewer」,或直接执行:

$ code --install-extension wake.big-log-viewer
方式 B · 从 Release 下载 .vsix

每个版本都附带打包好的安装包,在 Releases 页面 下载 .vsix,在扩展面板「⋯ → 从 VSIX 安装」里选它即可。

方式 C · 从源码打包
$ git clone https://github.com/uwakeme/large_log_check.git
$ cd large_log_check
$ npm install
$ npm run package

打包在项目根目录生成 .vsix,在扩展面板「⋯ → 从 VSIX 安装」里选它即可。

第一次使用

资源管理器里右键任意 .log / .txt 文件,选「打开大日志文件」。 进度条走完就是完整日志。每个文件在独立面板中打开,书签、注释、搜索状态都按面板隔离,关闭面板即释放资源。
